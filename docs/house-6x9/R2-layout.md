# РП54 R2 — раскладка и проверка деталей

Открыть: `/?screen=showcase#russian-house-6x9-r2`.
Исходная R1 остаётся отдельным примером: `#russian-house-6x9`.
Сохранённые документы не мигрируются и не переписываются.

## Что изменено

- Прямые участки ориентируются по размеру кирпича 250×120×65 мм, а не по глобальному чередованию осей.
- Целые кирпичи имеют приоритет; короткий остаток перераспределяется между соседними подрезками. Между отдельными деталями остаются предусмотренные 5 мм шва.
- Выбор начала раскладки учитывает реальные прямые швы предыдущего ряда. Это геометрическая проверка, не расчёт прочности перевязки.
- У проёмов выбирается замыкание, позволяющее включить тонкую полосу в один кирпич с вырезом. Контур занятой кладки при объединении не расширяется: пустоты и швы не «склеиваются».
- `solidParts` описывает один физический кирпич как связное объединение непересекающихся объёмов в миллиметрах. Общий габарит должен помещаться в заготовку. Одна такая деталь имеет один ID, редактируется, сохраняется и попадает в ведомость один раз.
- На сечении и в 3D внутренние границы этих объёмов не изображаются растворными швами.
- Диагностика строится по текущему редактируемому документу, а не по константе демопроекта. Есть переход к ряду, выбор детали, крупный план, высота точного сечения, подсветка в 3D и выгрузка ведомости CSV/геометрии JSON.

## Результат для встроенных моделей

| Проверка | R1 | R2 |
|---|---:|---:|
| Кирпичные детали | 4987 | 3396 |
| Целые прямоугольные 250×120×65 мм | 19 | 881 |
| Остальные прямые подрезки | 3946 | 1433 |
| Фасонные детали | 1022 | 1082 |
| Самостоятельные прямоугольные детали с размером <25 мм | 80 | 23 |
| Замечания к тонким участкам внутри составной формы | 0* | 43 |
| Совпадения прямых швов соседних рядов длиной ≥60 мм | 382 | 26 |

`*` В R1 нет составной формы: её геометрические фрагменты были отдельными деталями.
Поэтому нельзя выдавать уменьшение 80→23 за устранение всех тонких мест: 43 участка
внутри сложных кирпичей отдельно видны в проверках. 25 мм и 60 мм — пороги диагностики,
не нормативы. Самостоятельных 5-мм кирпичных вставок в R2 нет.

Машиночитаемые замечания с рядами и ID: [r2-layout-audit.json](r2-layout-audit.json).

## Сохранённые ограничения

Контуры корпуса, проёмы и основные дымовые пути R1 не перепроектированы. Раскладка швов
изменилась, поэтому объём собственно кирпича немного отличается; это не основание
вычислять закупку или расход раствора по числу деталей. Общая старая смета раствора
в этой задаче не заменялась; CSV — ведомость деталей, не количество покупаемых заготовок.
Не учтены совместный раскрой нескольких деталей из одного кирпича, пропил и отходы.

Клинчатые своды и стальные узлы не объявляются проверенными для строительства.
Оставшиеся замечания требуют разработки конкретных узлов, особенно пазух сводов,
полок и перекрыши. Программа не удаляет тонкие части автоматически и не заполняет
каналы ради красивой статистики.

## Проверки

- R1 сравнена с исходной версией по всему сериализованному проекту: изменений нет.
- Для R1/R2 проверены пересечения, геометрическая связь опор с основанием, размеры,
  три слоя перекрыши, все дымовые режимы и физический ход задвижек.
- Проверены сохранение R2 через Project/Draft, независимость копий, отбраковка
  несвязных/пересекающихся/слишком больших составных деталей, пустота вырезов после
  поворота, отсутствие ложных линий внутри кирпича и безопасная выгрузка CSV.
- Общая проверка каталога разделена по проектам без удаления пар коллизий: добавление
  R2 увеличило время старой общей проверки за её 30-секундный предел.
- Интерфейс проверяется рендерингом React на сервере; браузерные и визуальные проверки
  не выполняются по настройке пользователя.

R2 остаётся проектной моделью. Это не подтверждённая рабочая порядовка для кладки.
